# My Learning Journal

A responsive blog project built with **HTML**, **CSS**, and **JavaScript** as part of the **Scrimba Frontend Developer Career Path** solo projects.

## 📱 Features
- **Responsive Layout:** Works smoothly on mobile, tablet, and desktop screens using CSS Flexbox and Grid.
- **Dynamic Post Toggle:** "View More / View Less" button built with vanilla JavaScript to show or hide extra posts.
- **Multi-Page Design:**
  - `index.html` - Main blog listing page with a featured hero section.
  - `article.html` - Individual blog post page with recent post suggestions.
  - `about-me.html` - About Me page with bio and recent posts.

## 🛠️ Built With
- **HTML5**
- **CSS3** (Flexbox & CSS Grid)
- **JavaScript (Vanilla)**

## 🚀 Live Demo / Usage
Simply open `index.html` in your browser to explore the project!
